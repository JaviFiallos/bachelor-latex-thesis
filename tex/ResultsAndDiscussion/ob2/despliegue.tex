\subsubsection{Esquema de despliegue tecnológico}

El sistema y el agente conversacional comparten una única infraestructura: un servidor virtual en la nube en el que cada servicio se ejecuta en su propio contenedor. Un proxy inverso es la única entrada desde internet: atiende el dominio de la clínica, con un subdominio para la aplicación web y otro para el webhook del agente, y cifra la comunicación con HTTPS.
