El Objetivo 1 caracterizó el flujo clínico-administrativo, sus puntos críticos, las brechas normativas y las necesidades de comunicación con el paciente. Este objetivo traduce esos resultados en decisiones de diseño. Para ello, define la estructura lógica del agente, sus componentes funcionales, los mecanismos de integración con la plataforma de mensajería y el esquema de despliegue tecnológico. Como el agente opera sobre la agenda centralizada (N4 y RF07), también se diseña el sistema que lo contiene. Diagnosticar el flujo antes de implementar una solución permite anticipar barreras de adopción \cite{staras2021using}.
