\section{Objetivo General}

Desarrollar un sistema de información centralizado orientado a la gestión del flujo de información clínico-administrativa del centro odontológico Bellidental, incorporando un agente conversacional integrado a una aplicación de mensajería para la gestión automatizada de citas y la comunicación con el paciente, con el fin de reducir el tiempo promedio de gestión administrativa por ciclo completo de atención, durante el período Julio 2026 -- Diciembre 2026.

\section{Objetivos Específicos}

\begin{itemize}
    \item Analizar el flujo actual de información clínico-administrativa del centro odontológico Bellidental para identificar los procesos existentes, los requerimientos funcionales y normativos, y las necesidades de comunicación con el paciente mediante un agente conversacional.
    \item Diseñar la arquitectura del agente conversacional del Centro Odontológico Bellidental para la gestión automatizada de citas y la comunicación con el paciente, definiendo su estructura lógica, componentes funcionales, mecanismos de integración con la plataforma de mensajería y esquema de despliegue tecnológico.
    \item Implementar el sistema de información centralizado, incluyendo su módulo de agente conversacional integrado a una aplicación de mensajería, y evaluar la reducción del tiempo promedio de gestión administrativa por paciente.
\end{itemize}
